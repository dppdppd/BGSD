## Key Discoveries
- BIT 4.12.0 adds SVG feature shapes with `SVG_FILE`, `SVG_WIDTH_MM`, and optional `SVG_CLEARANCE_MM`.
- Electron-builder's Windows resource editing can hang when `/usr/bin/wine` points at WineHQ devel 11.9 in this environment.
- Debian Wine at `/usr/lib/wine/wine` runs `rcedit` successfully here; a temporary PATH shim avoids changing system links.

## What Didn't Work
- Fresh WineHQ devel prefixes and older saved Wine prefixes both timed out in `wineboot`.
- Running the initial all-platform release build through `/usr/bin/wine` stalled before the Windows portable exe was produced.
