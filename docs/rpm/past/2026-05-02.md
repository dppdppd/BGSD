## Key Discoveries
- **Electron preload runs sandboxed under `contextIsolation: true`** — arbitrary `require("./lib/...")` paths fail in packaged builds, taking the entire `contextBridge` down with them. Symptoms: `window.bgsd === undefined`, prefs don't load, "Choose Folder…" silently no-ops. Fix: only use `require("electron")` (whitelisted) in preload; everything else goes via IPC. The dev build (`npm start`) often masks this because it runs unsandboxed.
- **Manifest hash drifting from disk silently masks lib staleness.** `checkLibraryUpdates`/`updateLibraries` previously trusted `manifest.files[<path>]`; if a previous BGSD wrote the manifest before the file write actually succeeded (or the user manually edited the lib without going through Update Libraries), the chip would say "current" while the disk file was actually old. Fix: hash the on-disk file every check; manifest stays as a sidecar for `isRepoFile`.
- **AppImage replacement while running works on Linux.** `mv` over the live binary is safe — the kernel keeps the running process pointed at the old inode until exit. Only catch: chmod +x the new file BEFORE the rename, and verify the download has the ELF magic (0x7F 'E' 'L' 'F') so a truncated or HTML-error-page fetch doesn't replace the binary with garbage.
- **GitHub raw URLs need cache-busting.** `?_t=${Date.now()}` defeats both Chromium's HTTP cache and GitHub's CDN — without it, lib update checks could see stale content for ~5 min after upstream changes.

## What Didn't Work

## Build cadence guidance (new)
The maintainer flagged that pre-emptively rebuilding all three platform artifacts after every small change burns ~15 min/round and stacks stale binaries. New rule:
- **During iteration**: only `npm run build` (frontend + tests).
- The maintainer occasionally runs `./build-release.sh win` to spot-check Windows; commit the version bump it produces, but don't chain linux/mac builds in response.
- **At release time** (when the user says "release" / "ship"): build whatever's missing, then push + `gh release create`.
Persisted to `~/.claude/projects/.../memory/feedback_build_cadence.md` and noted in `AGENTS.md` so it carries forward.
