# 2026-05-01 — Ship v0.5.12 with rename, lid, lib fixes

## Accomplished
- Fixed lid defaults visibility: `getCloseContext` now resolves non-merged BOX_LID/LABEL closes to the lid/label schema context (previously only merged closes mapped via MERGED_INNER_ROLE), so virtual default rows render inside an existing flat lid block.
- Added Rename to the welcome-screen file context menu, including a new `rename-file` IPC handler with the same safety envelope as `delete-file` (validates path, refuses repo files, no path traversal, no overwrite, preserves extension).
- Discovered Rename was a no-op in production — Electron suppresses `window.prompt()` and returns null without UI. Replaced with the inline-edit pattern used for scene/element names (autofocused input, Enter/blur commits, Escape cancels).
- Fixed virtual-vs-real BOX_LID order mismatch: virtual lid block iterated schema-definition order while the real lid sorts alphabetically. Sorted virtual lid alphabetically in both App.svelte and ScadPreview.svelte so params don't visibly resort the moment the lid materializes.
- Fixed `lib/library-manager.js` so base lib files (boardgame_insert_toolkit_lib.4.scad, counter_tray_designer_lib.1.scad, global_constants.scad) always overwrite on update. Publisher/game examples still respect the writable-skip.
- Built and shipped v0.5.12 cross-platform: Linux AppImage (104M), unsigned Windows .exe (71M), unsigned macOS zip (96M). Pushed master and created the GitHub release.
- Set up rpm scaffolding (`docs/rpm/{context,past,present,future,reviews}`, `docs/spec/_template.md`).

## Key Discoveries
- **Electron suppresses `window.prompt()`** — returns null silently with no dialog. `confirm()` and `alert()` work; `prompt()` doesn't. Always use inline-edit or a Svelte modal in this app.
- **electron-builder v25 race in electron extraction** — when a previous run is killed mid-extract, `release/linux-unpacked/electron` ends up missing while the directory exists, and the next run fails with `chmod ... no such file or directory`. Fix: `rm -rf release/linux-unpacked release/win-unpacked release/mac` between attempts.
- **Don't run electron-builder targets in parallel** — `@electron/rebuild` mutates `node_modules` natives per arch; concurrent linux+mac+win runs collide. Sequential only (`set -e && --linux && --mac && --win`).
- **`set -e` + `tee` exit-code trap** — pipeline exit is `tee`'s, which is 0. Subshell failures get hidden. Always capture `${PIPESTATUS[0]}` for the real status when you `tee` a build.
- **Wine cross-compile setup on Debian 12** — needs `dpkg --add-architecture i386 && apt-get install -y --no-install-recommends wine wine32 wine64 p7zip-full`. `wine32:i386` pulls 130+ deps; the install phase takes longer than the unpack phase.
- **The host kernel string `4.4.302+` looks Synology** but the rootfs here is plain Debian 12 (apt + dpkg available, sudo authorized). Don't assume Synology DSM constraints based on `uname -a` alone.
- **Self-modification block** prevents adding `Bash(git push origin master)` to `.claude/settings.local.json` even when explicitly asked, because it bypasses a built-in safety guard. The user has to add it manually or push via `! git push origin master`.

## What Didn't Work

- Initial Rename UI used `window.prompt()` and silently no-op'd in the v0.5.12 binary that almost shipped. Caught only when the user reported the bug.
