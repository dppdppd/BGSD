# 2026-06-23 — BGSD

## Accomplished
- Diagnosed a user's "OpenSCAD not found" on macOS: BGSD needs the CLI binary *inside* OpenSCAD.app (`Contents/MacOS/OpenSCAD`), not the `.app` bundle. The old detection did a bare `existsSync` and otherwise fell back to a PATH lookup, so any wrong/bundle path produced the same vague error.
- Rewrote OpenSCAD detection (`main.js`): resolve a chosen `.app`/folder to its inner binary; broaden candidates to nightly/versioned builds, `~/Applications`, and Homebrew; make the macOS Browse dialog descend into bundles and save the resolved binary.
- Replaced the generic "not found" with specific, platform-aware reasons (missing path / folder / bundle-no-binary / OS-blocked, with macOS `xattr`, Windows lock, and Linux `chmod` hints); threaded `detail` through the live check, STL export, launch, and file-history paths.
- Added a Preferences **Test** button that runs `openscad --version` and reports the version or the precise failure.
- Ran an ultracode adversarial-review workflow (4 dimensions → per-finding verify). It confirmed 10 real defects; fixed all before release.
- Shipped **v0.5.36** (Linux AppImage, Windows `.exe`, macOS `.zip`) — https://github.com/dppdppd/BGSD/releases/tag/v0.5.36

## Key Discoveries
- `child_process.spawn()` reports a missing/non-executable/quarantined binary **asynchronously** via the `error` event, not as a synchronous throw — a `try/catch` around `spawn` is dead code for these cases. The launch path must verify (`execFile --version`) before spawning, or resolve from the `error` event, to surface the real reason instead of a false success.
- macOS quarantine (`com.apple.quarantine`) blocks exec but not `stat` — a quarantined binary passes `fs.statSync`/`isFile`, so resolution must not assume "stat-able ⇒ runnable".
- An `execFile` timeout returns `err.killed`/SIGTERM with `code === null` (not `ETIMEDOUT` on this Node), so a timeout must be classified explicitly or it reads as "not found".

## What Didn't Work
- The first-pass implementation looked complete and built green, but the adversarial review found 10 real defects (platform-foreign error messages, silent launch success on the targeted quarantine case, hard-coded `/Applications` path, non-deterministic bundle pick, timeout mislabeling). Build-green ≠ correct for cross-platform exec paths.
